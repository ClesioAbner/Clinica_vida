# Clínica Vida

Projeto de modernização do website da Clínica Vida.

O objetivo é criar uma presença digital moderna, profissional e intuitiva, melhorando a experiência dos pacientes e facilitando o acesso às informações e aos serviços da clínica.

O website inclui páginas informativas, apresentação das especialidades médicas, informações sobre os médicos, contactos e funcionalidades de marcação de consultas.

O projeto está a ser desenvolvido em WordPress, utilizando PHP para a lógica e funcionalidades, MySQL para a gestão dos dados, CSS para o design e JavaScript para as interações e animações da interface.

A modernização procura combinar um design cuidado, uma navegação simples e uma estrutura organizada, adaptada a diferentes dispositivos.

### Tecnologias utilizadas
- WordPress
- PHP
- MySQL
- HTML5
- CSS3
- JavaScript
