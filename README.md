# Clínica Vida

Projeto de modernização do website da Clínica Vida, com foco numa presença digital moderna, profissional e intuitiva, melhorando a experiência dos pacientes e facilitando o acesso aos serviços da clínica.

O website inclui páginas informativas, especialidades médicas, apresentação dos médicos, contactos e marcação de consultas.

A plataforma está a ser desenvolvida em WordPress, utilizando PHP para a lógica da aplicação, MySQL para a gestão dos dados, CSS para o design e JavaScript para as interações e animações da interface. O design é adaptável a diferentes dispositivos.

### Funcionalidades e integrações

- **Marcação de consultas:** facilita o agendamento e a gestão de consultas.
- **Pagamentos online:** integração com M-Pesa para pagamentos digitais.
- **Notificações:** envio de lembretes e alertas de consultas por SMS e email.
- **Bot para WhatsApp:** automatização de interações e respostas através de workflows desenvolvidos no n8n.
- **Gestão de dados:** organização das informações necessárias ao funcionamento da plataforma.

### Tecnologias utilizadas

- WordPress e PHP
- MySQL
- HTML5 e CSS3
- JavaScript
- M-Pesa API
- n8n para automação de workflows
- Integrações de SMS, email e WhatsApp
